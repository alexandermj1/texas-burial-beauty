# Two-column seller summary

## What will change
- Replace the current scattered seller header with one compact summary at the top of each seller record.
- Use a narrow left column for the full pipeline and latest communication, with the current stage clearly highlighted.
- Use a wider right column for property, contact, ownership, pricing, listing-option, and payment information.
- Keep the existing ivory, sage, terracotta, and ink styling, with thin dividers and restrained emphasis rather than many separate cards.

## Information shown
- Pipeline: No attachments, Attachments, Quoted, Accepted, Tree sent, Tree done, Docs out, Docs returned, Complete.
- Latest communication: whether it came from the seller or was sent by TCB, its date, and elapsed time.
- Property: cemetery, plot type, deed location, selling location, and plot count.
- Seller: original submission date, contact details, deed owners, relationship, and additional form information.
- Financials: cemetery price per plot, transfer fee, TCB quote per plot, resale price per plot, listing option, and payment received.

## Editing and behavior
- Make “Locations – being sold” and “# of plots being sold” directly editable and save them to the existing seller record.
- Preserve the current stage-moving and listing-option behavior while presenting those controls inside the new summary.
- Show clear placeholders when older records do not contain a requested value.
- Stack the two columns cleanly on phones while keeping the desktop view compact.

## Verification
- Check a populated seller record and an older record with missing fields.
- Confirm both editable values save and remain correct after reloading.
- Confirm the highlighted stage matches the pipeline bucket and the communication direction/date are accurate.
- Review desktop and mobile layouts for clipping, overlap, and excessive height.
